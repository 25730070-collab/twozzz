# 자동 점검 (tests/)

화면을 실제 브라우저(Chromium)로 열어 눌러 보고 결과를 확인한다. **카카오 키·네트워크가 필요 없다** — 카카오 응답과 지도 라이브러리(Leaflet)는 가짜로 대신한다.

```
npm install          # playwright 설치 (처음 한 번)
npx playwright install chromium
npm test
```

## 무엇을 확인하나
| 영역 | 확인 내용 |
|---|---|
| 경로 비교 | 우회 경유지 후보로 안전 경로가 빠른 경로와 달라지는지, 호출 횟수 제한, 시간 제한(1.35배), 대안이 없을 때 솔직한 안내, 키 오류 문구 |
| 안내(내비) | 연습 모드에서는 음성 없음, 실제 GPS 모드에서만 음성 |
| 사고 유형 맞춤 안내 | 가장 많은 사고 유형 → 주의 문구 (맞는 게 없으면 문구 없음) |
| 자동완성 | 후보 표시·키보드·선택, 고른 장소의 좌표를 다시 검색 없이 사용, Esc가 입력을 지우지 않는지 |
| 지도 | 구간 상세 지도가 맨 위, 위험 구간 목록 지도, 지도를 못 불러올 때의 대체 화면 |
| 오프라인 | 한 번 열어 둔 뒤 연결을 끊어도 목록·홈·상세가 열리는지, 오프라인 띠 |
| 화면 | 하단 문구(푸터) 없음, 데이터 안내 시트, 375·393·440px 가로 넘침 없음, 자바스크립트 오류 없음 |

## 한계
- 가짜 응답으로 확인한 것이라 **실제 카카오 응답·실제 지도 화면·실제 기기 음성은 확인하지 않는다.**
- 경로 시험은 `data/` 의 사고 다발지점 위치에 맞춘 좌표를 쓴다. 데이터를 바꾸면 시험 좌표를 다시 정해야 할 수 있다.
