# 자동 점검 (tests/)

화면을 실제 브라우저(Chromium)로 열어 눌러 보고 결과를 확인한다. **카카오 키·네트워크가 필요 없다** — 카카오 응답과 지도 라이브러리(Leaflet)는 가짜로 대신한다.

```
npm install          # playwright 설치 (처음 한 번)
npx playwright install chromium
npm test            # 브라우저 화면 시험 (115개)
npm run test:unit   # 계산 시험 (13개)
npm run test:server # 회원 서버 시험 (17개)
npm run test:all    # 위 셋을 차례로
```

## 무엇을 확인하나
| 영역 | 확인 내용 |
|---|---|
| 경로 비교 | 우회 경유지 후보로 안전 경로가 빠른 경로와 달라지는지, 호출 횟수 제한, 시간 제한(1.35배), 대안이 없을 때 솔직한 안내, 키 오류 문구 |
| 안내(내비) | 연습 모드에서는 음성 없음, 실제 GPS 모드에서만 음성 |
| 안내 · 진행 방향 지도 · 3D | 지도 방향 = 경로 진행 방향, 지도는 차 방향의 반대로 돌고 눕힌 상태(원근 투영 + rotateX)에서 차는 화면 고정 그림, 0~360° 어느 방향에서도 눕힌 화면 모서리가 비지 않음, **눕힌 지도의 좌표 계산이 실제 브라우저가 그린 위치와 맞는지(오차 1.5px 이내)**, 경계(350°→10°)에서 20°만 회전, 주행 중 화면 꺼짐 방지, 전체 보기·나침반·다발지점 보기에서 회전 해제 |
| 안내 · 남은 시간 · 교통 막대 · 제한속도 | 도로별 소요 시간 합으로 남은 시간 계산, 교통 막대 색 순서(원활→정체→서행)와 지난 길 제외, 연습의 도착 시각 고정, 경로에서 벗어난 카메라 걸러내기, 500m 앞부터 제한속도 표지·지나면 사라짐, 제한속도 값이 없는 카메라는 "단속"으로만 표시, GPS 속도가 제한속도를 넘으면 빨강·10km/h 이내는 노랑·기기가 속도를 안 주면 "-", 교통 정보·카메라 파일이 없을 때 숨기고 알림 |
| 가입 · 로그인 · 탈퇴 | 서버가 없으면 실습 모드, 서버가 있으면(**실제 server/ 프로세스 + 메모리 DB**) 인증번호 발송·틀린 번호·가입·로그인·로그아웃·없는 계정·중복 가입·탈퇴·재가입 |
| 사고 유형 맞춤 안내 | 가장 많은 사고 유형 → 주의 문구 (맞는 게 없으면 문구 없음) |
| 자동완성 | 후보 표시·키보드·선택, 고른 장소의 좌표를 다시 검색 없이 사용, Esc가 입력을 지우지 않는지 |
| 지도 | 구간 상세 지도가 맨 위, 위험 구간 목록 지도, 지도를 못 불러올 때의 대체 화면 |
| 오프라인 | 한 번 열어 둔 뒤 연결을 끊어도 목록·홈·상세가 열리는지, 오프라인 띠 |
| 화면 | 하단 문구(푸터) 없음, 데이터 안내 시트, 375·393·440px 가로 넘침 없음, 자바스크립트 오류 없음 |

## 계산 시험 (`npm run test:unit`)
브라우저 없이 `js/navinfo.js` 와 `tools/build_cameras.mjs` 만 확인한다 (13개): 남은 시간(도로별 합·전체에 맞춤·도로 정보 없을 때 거리 비율), 시간·시각 표기, 교통 구간 합치기, 꼭짓점 사이에 있는 카메라까지의 거리, 경로 위 카메라 고르기, 속도 단계, CSV 읽기(따옴표·줄바꿈)·CP949 인코딩·서울 필터·제한속도 검증·중복 제거·영문 API 항목 이름·명령줄 도구.

## 회원 서버 시험 (`npm run test:server`)
`server/` 의 로직을 메모리 SQLite 와 가짜 발송기로 확인한다 (Node 22.5 이상). 인증번호 평문 미저장, 시도 5회 제한, 3분 만료, 1회용, 재전송 간격·시간당 한도, IP 한도, 중복 가입, 위조·만료·재사용 토큰, 로그인·세션 만료·탈퇴 삭제, 입력 검사, 잘못된 JSON·큰 요청, 메일 실패(502), CORS, SQL 주입 시도, `index.js` 실행·정적 파일 노출 차단.

## 한계
- 가짜 응답으로 확인한 것이라 **실제 카카오 응답(교통 정보 포함)·실제 지도 화면(회전·눕힌 타일 포함)·실제 기기 음성·화면 꺼짐 방지는 확인하지 않는다.** 카카오 응답의 모양은 공식 문서의 항목(`roads.duration`·`traffic_state`·`traffic_speed`)대로 만든 것이다.
- 단속 카메라는 시험용으로 만든 가짜 목록이다. **실제 공공데이터 파일은 확인하지 못했다.**
- 회원 서버는 **실제 MySQL과 실제 메일 발송을 확인하지 않았다** (메모리 SQLite·가짜 발송기로 확인).
- 경로 시험은 `data/` 의 사고 다발지점 위치에 맞춘 좌표를 쓴다. 데이터를 바꾸면 시험 좌표를 다시 정해야 할 수 있다.
