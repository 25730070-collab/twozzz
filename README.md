# PRD v0.4

기준: 와이어프레임(`pages/v0.1/index.html`, 2026-10-12) + 사이트맵 기준 8화면 설명. 현재 구현과의 차이는 아래 변경 이력에 정리

## 1. 개요

| 항목 | 내용 |
|---|---|
| 서비스 | Safe Drive |
| 가치 제안 | 초행길도 안심하고, 사고 위험도 낮은 길로 |
| 한 문장 설명 | 출발지·도착지만 입력하면 위험 구간을 피해 알려 주는 모바일 웹 서비스 |
| 핵심 사용자 | 초행길을 운전하는 사람 |
| 대표 과업 | 출발지·도착지를 입력해 경로의 위험 구간을 확인하고, 마음에 드는 경로를 저장 |
| 데이터 | 도로교통공단 공공 사고 데이터 (구간명, 사고 건수, 위험등급, 좌표 등) |
| 저장 방식 | 로그인 없음, 모든 사용자 기록은 LocalStorage |
| 플랫폼 | 모바일 화면(하단 탭 바 + TOP 버튼) |

## 2. 범위

| 포함 | 제외 |
|---|---|
| 경로 입력과 모드 선택, 위험 구간 목록(필터·정렬), 구간 상세, 위험등급 안내, 즐겨찾기, 최근 검색 | 로그인·회원가입, 서버 저장, 실시간 교통 정보, 길 안내(내비게이션) |
| 결과 없음·오류·저장 없음 상태 화면 | |
| 심화 트랙: 지도 뷰(Naver Maps API), 사고 유형 요약 | |

## 3. 화면 (8개)

| # | 화면 | 목적 | 주요 데이터 |
|---|---|---|---|
| 1 | 홈 | 출발지·도착지·모드를 입력해 탐색 시작 | origin, destination, routeMode, recentSearch[], favoriteRoute[] |
| 2 | 위험 구간 목록 (결과 있음) | 경로의 위험 구간을 등급·사고 건수와 함께 확인 | segmentId, roadName, roadType, accidentCount, riskLevel |
| 3 | 위험 구간 목록 (결과 없음·오류) | 상태별 안내와 복구 행동 제공 | screenState |
| 4 | 구간 상세 | 한 구간의 사고 건수·주소·도로유형 확인, 재탐색, 즐겨찾기 | lat, lng, address, accidentTypeBreakdown, isFavorite |
| 5 | 위험등급 안내 | 등급 4종의 의미와 색상 범례 | (정적 문구) |
| 6 | 마이 · 즐겨찾기 | 저장한 경로 확인과 해제 | favoriteRoute[] |
| 7 | 마이 · 최근 검색 | 최근 검색 10건 확인과 재탐색 | recentSearch[] |
| 8 | 필터·정렬 | 등급·도로유형·정렬 조건 선택 | riskLevel[], roadType[], sortBy |

공통: 하단 탭 바(홈 · 위험 구간 · 마이), TOP 버튼. 구간 상세·위험등급 안내·필터는 탭 바를 숨기고 ←로 복귀.

## 4. 기능 요구사항

| 구분 | 기능 | 완료 조건 |
|---|---|---|
| Must | 경로 입력 | 출발지와 도착지를 모두 입력해야 탐색 버튼이 활성화된다 |
| Must | 모드 선택 | 기본 / 안전우선 / 4등급 제외 중 하나를 선택하면 결과에 반영된다 |
| Must | 위험 구간 목록 | 조건에 맞는 구간이 등급 배지·사고 건수와 함께 나오고, 결과 건수가 표시된다 |
| Must | 필터·정렬 | 위험등급(다중), 도로유형(다중), 사고 많은 순 정렬을 적용·초기화할 수 있다 |
| Must | 구간 상세 | 사고 건수·도로유형·주소·위험등급이 표시된다 |
| Must | 즐겨찾기 | 저장·해제가 가능하고 새로고침해도 유지된다 (LocalStorage) |
| Must | 최근 검색 | 최대 10건을 검색 시각순으로 보관하고, 탭하면 같은 조건으로 재탐색한다 |
| Must | 상태 화면 | 로딩, 결과 없음(마지막 조건 해제), 오류(다시 시도), 저장 없음을 구분해 보여 준다 |
| Should | 위험등급 안내 | 등급별 의미와 색상(4 빨강, 3 주황, 2 노랑, 1 초록)을 설명한다 |
| 심화 | 지도 뷰 | 구간 좌표로 지도에 표시하고, API 실패 시 텍스트 정보만으로 판단할 수 있다 |
| 심화 | 사고 유형 요약 | 추돌·좌회전·보행자 등 집계를 보여 주고, 데이터가 없으면 영역을 숨긴다 |
| 심화 | 재탐색 | 현재 구간을 제외하고 경로를 다시 찾는다 |

## 5. 사용자 흐름

| 흐름 | 단계 |
|---|---|
| **A. 경로 탐색** (대표) | 홈 → 출발·도착·모드 입력 → 위험 구간 목록 → 구간 상세 |
| **B. 조건 조정** | 위험 구간 목록 → 필터·정렬 → 적용 → 목록 갱신 |
| **C. 재탐색** | 구간 상세 → 이 구간 피해서 재탐색 → 위험 구간 목록 |
| **D. 저장·재사용** | 구간 상세 → 즐겨찾기 저장 → 마이 → 항목 탭 → 재탐색 |
| **E. 최근 검색** | 마이 → 최근 검색 → 항목 탭 → 같은 조건으로 재탐색 |
| **예외** | 결과 없음 → 마지막 조건 해제 / 오류 → 다시 시도 (즐겨찾기·최근 검색은 유지) / 저장 없음 → 목록으로 이동 안내 |

## 6. 사이트맵

홈 ─ 위험 구간 목록(필터·정렬 시트) ─ 구간 상세(위험등급 안내) / 마이(즐겨찾기 · 최근 검색)

## 7. 데이터 항목

**출처:** 한국도로교통공단 지자체별 사고 다발지역정보 조회 서비스(`frequentzoneLg`, 공공데이터포털). 서울 25개 구(`siDo=11`)를 구 코드로 하나씩 조회한다. 연 1회 갱신, 2019~2025년 제공. 응답 항목은 활용가이드와 대조해 확인했다.

| API 항목 | 앱 항목 | 화면 |
|---|---|---|
| `spot_nm` | 구간 이름·주소 | 목록·상세 |
| `occrrnc_cnt` | 사고 건수 | 목록·상세 |
| `la_crd`, `lo_crd` | 위도·경도 | 경로 비교(위험 구간 매칭) |
| `caslt_cnt`, `dth_dnv_cnt`, `se_dnv_cnt`, `sl_dnv_cnt`, `wnd_dnv_cnt` | 사상자·사망·중상·경상·부상신고 | 상세 (값이 있을 때만) |
| (가공) | 위험등급 1~4 | 수집 데이터의 사고 건수 사분위수 |


| 항목 | 형태 | 설명 |
|---|---|---|
| origin, destination | 문자열 | 출발지·도착지 |
| routeMode | 지정값 | 기본 / 안전우선 / 4등급 제외 |
| segmentId, roadName | 문자열 | 구간 식별자, 구간명 |
| roadType | 지정값 | 대로 / 이면도로 / 골목길 |
| accidentCount, riskLevel | 숫자 | 사고 건수, 위험등급 1~4 |
| lat, lng, address | 숫자·문자열 | 좌표, 주소 |
| accidentTypeBreakdown | 집계 | 사고 유형별 건수 (심화) |
| favoriteRoute[], recentSearch[] | 배열 | LocalStorage 저장 (savedAt, searchedAt 포함, 최근 검색 최대 10건) |

## 8. 비기능 요구사항

- 로그인 없이 모든 화면을 이동할 수 있다.
- 오류 상태에서도 즐겨찾기·최근 검색 데이터는 유지된다.
- 위험등급 색상은 모든 화면에서 같은 규칙으로 고정한다.
- 외부 API(지도)가 실패해도 텍스트 정보만으로 판단할 수 있어야 한다.
