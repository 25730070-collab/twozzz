# 단속 카메라 · 제한속도 데이터 만들기

안내 화면의 **제한속도 표지**는 공공데이터 *전국무인교통단속카메라표준데이터*에서 만든 `data/speed_cameras.json` 이 있을 때만 나옵니다. 파일이 없으면 표지를 보여 주지 않고, 화면 문구로 "데이터 파일이 없어 표시하지 않아요"라고 알립니다 (값을 지어내지 않아요).

## 만드는 순서

1. 공공데이터포털(data.go.kr)에서 **전국무인교통단속카메라표준데이터**(파일데이터, 데이터 번호 15028200)를 찾아 CSV 로 내려받습니다. 파일데이터는 로그인 없이 받을 수 있어요. (정확한 주소는 확인하지 못했으니 포털에서 이름으로 검색하세요.)
2. 프로젝트 폴더에서 한 줄 실행합니다. 받은 파일 경로를 따옴표로 감싸 주세요.

   ```
   cd C:\Users\user\twozzz
   node tools/build_cameras.mjs "C:\Users\user\Downloads\받은파일.csv"
   ```
3. 끝에 나오는 요약을 눈으로 확인합니다.
   - `서울 N곳` 이 0 이면 열 이름(위도·경도·시도명)이 달라서 못 읽은 거예요. 그 줄 알려 주세요.
   - `제한속도별` 에 30·50·60·80 같은 값이 보여야 정상입니다.
   - `단속구분별` 의 숫자(코드)는 뜻을 확인하지 못해서 받은 값 그대로 보관합니다.
4. `data/speed_cameras.json` 이 만들어졌습니다. 깃허브에 올릴 때 같이 `git add data/speed_cameras.json` 하세요.

## 알아 둘 것

- 모든 도로의 제한속도가 아니라 **단속 카메라가 있는 지점**의 제한속도입니다. 카카오 길찾기 API에는 도로별 제한속도가 없어요.
- 카메라가 보는 방향은 구분하지 못해서, 같은 길 반대 방향 카메라가 함께 표시될 수 있습니다. 경로에서 35m 안의 카메라만 쓰지만 큰길은 양방향이 겹쳐요.
- 표준데이터는 지자체가 달마다 모아서 **빠진 곳이 있을 수 있습니다.** 표지가 없다고 단속이 없는 건 아니에요.
- 이동식 단속·구간단속 구간 전체는 담지 못합니다.
- 받은 CSV 가 한글 윈도우 인코딩(CP949)이어도 자동으로 읽습니다. 서울이 아닌 줄은 버립니다.
